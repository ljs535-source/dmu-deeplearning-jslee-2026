# 미니프로젝트 2분 발표 — 슬라이드 5장 가이드

> **제출**: 12/4(금) 수업 1시간 전까지 LMS 에 **PDF** 업로드 (교수 PC 에서 엽니다)
> **시간**: 발표 2분 + 질의 1분 · 장당 약 20~25초
> **원칙**: 코드 화면은 넣지 않는다 · 장마다 **숫자 하나, 그림 하나** · 글씨는 크게

| 장 | 제목 예 | 넣을 것 | 말할 것 (예시) |
|:---:|---|---|---|
| **1** | 무엇을 분류했나 | 주제 · 클래스 이름 · 이유 한 줄 | "길고양이 세 마리를 사진으로 구분해 보고 싶었습니다." |
| **2** | 데이터 | 클래스별 예시 사진(문장) · 장수 | "직접 찍은 사진 클래스당 40장, 훈련 32장·검증 8장으로 나눴습니다." |
| **3** | 기준선 → 실험 | 실험 기록표 축약 (바꾼 것 · 정확도 두 열) | "기준선 71% 에서 전이학습으로 바꾸자 90% 가 됐습니다." |
| **4** | 최종 결과 | 곡선 **또는** 혼동행렬 하나 | "가장 많이 헷갈린 건 A 와 B 였고, 둘 다 검은 무늬가 있어서인 것으로 보입니다." |
| **5** | 결론 | 결론 한 문장(4요소 중 둘 이상) · 배운 점 | "학습 파라미터는 1% 수준인데 더 정확해서 전이학습을 고르겠습니다." |

> 위 "말할 것" 의 숫자는 예시입니다. **반드시 내 결과의 숫자**로 바꾸세요.

## 리허설 체크

- [ ] 소리 내어 2분 안에 끝난다 (넘으면 슬라이드를 줄인다)
- [ ] 3장 표의 글씨가 뒤에서도 보인다
- [ ] 5장 결론에 숫자가 있다
- [ ] 예상 질문 하나에 답을 준비했다 — "검증 데이터는 몇 장? 무엇과 가장 헷갈렸나? 정확도 말고 무엇을 봤나?"
